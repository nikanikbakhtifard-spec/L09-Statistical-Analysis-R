# Statistical Analysis in R

## Project Overview

This academic project applies descriptive and inferential statistical methods to a workshop dataset using R and R Markdown.

The analysis explores revenue distributions, variability, concentration, and relationships between quantitative and categorical variables.

## Statistical Methods

**1. Descriptive Statistics**
- Measures of central tendency and dispersion
- Distribution shape and skewness
- Data visualization

**2. Variability and Concentration**
- Standard deviation and coefficient of variation
- Chebyshev's inequality
- Lorenz curve and Gini coefficient

**3. Categorical Association**
- Chi-square test of independence
- Cramér's V
- Eta-squared

**4. Quantitative Association**
- Pearson correlation
- Spearman rank correlation
- Correlation analysis and visualization

## Key Results

- Mean monthly revenue: €7,905.49
- Revenue Gini coefficient: 0.2960
- Chi-square statistic: 35.7298
- Cramér's V: 0.2363

## Reproducibility

The analysis uses the `L09_workshops.csv` dataset. To reproduce the results, place the dataset in the same directory as the R Markdown file and render the document in an R environment with the required packages.
